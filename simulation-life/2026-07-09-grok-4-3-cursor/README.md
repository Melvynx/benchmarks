# Petri Dish — Living Ecosystem

Educational artificial-life sandbox: plant food, prey, and predators interact through an honest energy economy. Populations boom, crash, and oscillate from the rules — not from scripted waves.

## Run

```bash
pnpm install
pnpm dev
```

Then open the local URL Vite prints.

## What to try

- **Balanced ecosystem** — classic out-of-phase predator–prey cycles  
- **High predator pressure** — prey collapse, then predator decline  
- **Prey paradise** — soft predation, food surplus  
- **Fragile equilibrium** — tip the sliders and watch recovery or collapse  
- **Low food / ice age** — starvation pressure dominates  

Drag the dish to orbit, scroll to zoom, click a creature to inspect. Charts show real recorded history (population, phase space, evolving traits, energy histogram).
