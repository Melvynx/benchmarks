<brief>
Build Cowdie, a playful 3D virtual pet experience inspired by Tamagotchi.

Create a pet that the user can feed and care for. Make it feel alive, expressive, and enjoyable to spend time with. Feeding must be a real interaction with a visible response from the pet.
</brief>

<freedom>
You have full creative control over the features, visual style, pet design, environment, interactions, progression, and technical implementation. Choose what makes the strongest experience. There is no prescribed feature checklist beyond a 3D pet that we can feed and care for like a Tamagotchi.

Build a complete, polished, functional web app. Own the product and design decisions.
</freedom>

Work only inside the current working directory. Do not read, list, search, or edit files outside the current working directory. Treat it as a standalone project root.
During setup, configure your app and package scripts to use port 9366, then use that port for runtime verification.
Use pnpm exclusively if dependency installation or package scripts are needed. Do not use npm.
Set the browser title and the primary visible title to your model name, using only identity information already available to you. Add nothing else to either title.
Run the relevant checks yourself. Do not edit files outside the current working directory.
