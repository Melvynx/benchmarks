Built **GPT-6**, a responsive local email client with 25 seeded messages, conversation reading, search, folder navigation, bulk actions, labels, starring, archive and Trash, plus compose, drafts, replies, and sending. Mailbox changes persist in browser storage.

`pnpm run build` and `pnpm run test` pass. The interaction tests cover the main mail workflows. I could not complete a visual browser check: this sandbox rejected binding port 9177 and blocked the browser launch.

Run it locally with `pnpm run dev`; it is configured for port **9177**.
