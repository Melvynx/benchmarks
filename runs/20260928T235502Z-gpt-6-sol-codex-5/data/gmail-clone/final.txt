Built **GPT-6**, a responsive local email client on port 9180. It includes a seeded mailbox, search, conversation reading, folder navigation, bulk actions, labels, and compose with saved drafts and sending. Mailbox state persists on the device.

`pnpm run build` and `pnpm run test` pass. I could not complete browser verification here: Portly was unavailable, and the environment denied binding to port 9180. To run the app locally, use `pnpm run dev` from this directory.
