Built a responsive, local-first Gmail-inspired client titled **Codex**. It includes 28 seeded conversations, mailbox navigation, search, threaded reading, labels, stars, archive, trash, snoozing, drafts, sending, attachments, keyboard shortcuts, themes, and saved preferences.

**Checks:** `pnpm install --offline` and `pnpm build` passed. Function-level interaction checks passed for search, folders, read state, archive/trash/snooze with undo, draft saving, sending, and persistence.

**Runtime limitation:** I couldn’t verify the live UI on port 9102. Portly reports its executable is missing, and the direct server start is blocked by `EPERM` in this environment. The app is configured to run with `pnpm dev` on port 9102.
