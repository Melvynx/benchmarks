**GPT Image 2** is now live in Thumbfa.st.

You're not imagining it. The new OpenAI image model shipped, and we've updated Thumbfa.st to use the official API model name: `gpt-image-2`.

## What's New

- **GPT Image 2** is now available in the model picker for paid plans
- Existing `gpt-image-1.5` selections automatically resolve to **GPT Image 2**
- Thumbfa.st now calls OpenAI's official API model ID: `gpt-image-2`
- The picker now shows pricing details without inventing fake per-image token numbers

## Official Pricing

Thumbfa.st now uses OpenAI's official pricing page as the source of truth for this model.

Current OpenAI pricing for **GPT Image 2**:

- **Image input:** `$8 / 1M tokens`
- **Cached image input:** `$2 / 1M tokens`
- **Image output:** `$30 / 1M tokens`
- **Text input:** `$5 / 1M tokens`
- **Cached text input:** `$1.25 / 1M tokens`
- **Text output:** `$10 / 1M tokens`

Source: [OpenAI API Pricing](https://openai.com/api/pricing/)

## Thumbfa.st Credit Cost

Inside Thumbfa.st, GPT Image 2 is currently priced at **1 token usage per image**.

That is our internal product pricing, not a claim about a fixed OpenAI token count per generated image.

## Zero-Downtime Upgrade

No migration needed.

If you previously used GPT Image 1.5, Thumbfa.st automatically upgrades that selection to GPT Image 2 behind the scenes.
