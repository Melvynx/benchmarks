A new beta version of Thumbfa.st is now live. The editor feels faster, generation feedback is clearer, public pages share better previews, and the generation pipeline is more reliable behind the scenes.

The important part: **Pro now includes 150 thumbnails per month for the same $19/month price**.

## What Changed

- **More reactive app experience**: thumbnail workflows, organization pages, and content routes now stay in sync with fresher metadata and faster client updates.
- **More reliable generations**: availability checks now happen before a job starts, so fewer requests fail after launch.
- **Better custom API key checks**: account setup feedback is clearer before generation starts, without exposing internal routing details.
- **More value on Pro**: Pro includes **150 thumbnails per month** with no price increase.
- **Cleaner editor details**: thumbnail detail views now include quicker copy, download, and edit actions, keyboard shortcuts, and clearer status information for admins.
- **Stronger generation monitoring**: admin generations, logs, and errors now show progress timelines, duration hints, diagnostics, and full-size output previews.
- **Better public metadata**: changelog, docs, blog, public tools, organization pages, and generated resources now expose more accurate titles, canonical URLs, and share images.

## Why It Matters

The new stack reduces the operational cost per generation and gives us better visibility into failures. That lets us raise the Pro plan allowance without changing the price.

More thumbnails means more drafts, more A/B test candidates, and more room to iterate before publishing.
