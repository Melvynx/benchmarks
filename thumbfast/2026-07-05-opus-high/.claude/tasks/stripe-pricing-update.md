## Steps to Update Stripe

### 1. Create New Products/Prices in Stripe Dashboard

Go to: https://dashboard.stripe.com/products

**For each new pack:**

1. Click "Add product"
2. Name: "10 Credits" / "50 Credits" / "150 Credits"
3. Pricing: One-time, $2.99 / $12.99 / $34.99
4. Copy the Price ID (starts with `price_`)

### 2. Update Environment Variables

```env
# Update these in your .env file
STRIPE_CREDITS_10_PRICE_ID=price_xxx  # New $2.99 price
STRIPE_CREDITS_50_PRICE_ID=price_xxx  # New 50 credits pack
STRIPE_CREDITS_150_PRICE_ID=price_xxx # New 150 credits pack
```

**Note:** Remove the old `STRIPE_CREDITS_100_PRICE_ID` and `STRIPE_CREDITS_500_PRICE_ID`

### 3. Archive Old Products (Optional)

In Stripe Dashboard, archive the old credit pack products to prevent accidental use.

## Yearly Subscription Fix

A bug was fixed where yearly subscribers only received credits once per year instead of monthly.

**Solution implemented:**

1. **Webhook-based** (backup): The Stripe webhook also checks yearly subscriptions
2. **Cron job** (primary): Daily cron at 9:00 UTC checks all yearly subscriptions

**Cron job details:**

- Path: `/api/cron/monthly-credits`
- Schedule: Daily at 9:00 UTC (`0 9 * * *`)
- Config: `vercel.json`

**Required in production:**

- Set `CRON_SECRET` in Vercel environment variables (auto-generated by Vercel)
