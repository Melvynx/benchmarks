# Design System: GPT-5.6 Sol

## 1. Overview

**Creative North Star: "The Quiet Workbench"**

This is a familiar mail workspace tuned for fast scanning and calm control. Its structure follows proven inbox conventions while spacing, state feedback, and responsive composition are treated with unusual care. Gmail supplies the workflow grammar, Linear supplies compact precision, and Apple Mail supplies the mobile reading rhythm.

The system rejects decorative dashboard cards, oversized type, novelty navigation, generic gradients, glass effects, and inert controls. Motion is responsive and brief, used only to explain state changes.

**Key Characteristics:**

- Dense without feeling cramped
- Restrained color with a warm red action anchor
- Content-first surfaces and quiet chrome
- Familiar interaction patterns with clear feedback
- Structural desktop-to-mobile adaptation

## 2. Colors

The palette is restrained: neutral working surfaces, dark readable ink, a warm red primary, and semantic color reserved for state.

**The Rare Accent Rule.** Primary color appears on selection, compose, focus, and decisive actions. It never decorates inactive chrome.

## 3. Typography

One system sans family carries the interface. The scale is compact and fixed, with weight and contrast creating hierarchy instead of display sizing.

**The Scan First Rule.** Sender, subject, snippet, metadata, and labels remain visually distinct at inbox density.

## 4. Elevation

The interface is flat by default. Tonal layers establish structure; compact shadows appear only on floating compose, menus, and transient feedback.

## 5. Components

Controls use one coherent shape and state vocabulary. Rows expose useful actions on hover and selection, fields retain visible focus, and navigation becomes a mobile drawer rather than shrinking in place.

## 6. Do's and Don'ts

### Do:

- **Do** keep primary mailbox actions immediately discoverable.
- **Do** preserve keyboard focus and generous touch targets at narrow widths.
- **Do** use content density appropriate to a working inbox.

### Don't:

- **Don't** use decorative dashboard cards, oversized type, or low-density layouts.
- **Don't** use novelty navigation, glass effects, excessive rounding, or generic AI gradients.
- **Don't** leave controls that look interactive without a meaningful local behavior.
