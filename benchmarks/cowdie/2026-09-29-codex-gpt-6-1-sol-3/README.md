# Cowdie

A cozy, responsive 3D pet meadow built with Three.js and Vite. Care for Clover with animated feeding, petting, ball play, baths, and naps. Includes persistent care stats, friendship levels, memories, ambient day/night controls, and optional interaction sounds.

## Run

```sh
pnpm install
pnpm dev
```

The development server uses port **9192**. Production scripts are `pnpm build` and `pnpm preview` (also port 9192).

Care progress is saved locally in the browser. Use the four care buttons beneath the meadow to choose an activity. Click Clover herself to pet her, or focus the meadow and press Enter. Choose one of three snacks and press Feed Clover to watch her eat.
