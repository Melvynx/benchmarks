# SaveIt.now landing page

- This is a self-contained Vite, React, and TypeScript landing page.
- Use `pnpm` exclusively for dependencies and package scripts.
- Keep all work inside this directory.
- The six supplied campaign images are under `public/images/landing-v2/`. The page renders the optimized WebP derivatives in `public/images/landing-v2/web/` (generated with `cwebp` at 1920w, 1080w, and a tiny blur placeholder); keep the originals untouched.
- The dev and preview servers run on port 9322.
- Preserve a working responsive page and verify both the build and the configured local port.
