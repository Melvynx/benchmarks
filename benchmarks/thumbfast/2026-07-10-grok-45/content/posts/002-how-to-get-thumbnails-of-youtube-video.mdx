Most people assume you need the YouTube Data API to get a video's thumbnail. You don't. YouTube stores every thumbnail on a public CDN, and the URL pattern is completely predictable.

Here's the full technique — and why we built a free tool so you never have to think about it.

## The URL Pattern

YouTube thumbnails live on `i.ytimg.com`. The structure is:

```
https://i.ytimg.com/vi/{VIDEO_ID}/{SIZE}.jpg
```

That's it. No API key. No OAuth. No scraping. Just a direct image URL.

For a video at `https://www.youtube.com/watch?v=dQw4w9WgXcQ`, the video ID is `dQw4w9WgXcQ`, and the max resolution thumbnail is:

```
https://i.ytimg.com/vi/dQw4w9WgXcQ/maxresdefault.jpg
```

## The Five Sizes

YouTube stores each thumbnail in multiple resolutions. Here's every size key you can use:

| Key             | Dimensions | Aspect Ratio |
| --------------- | ---------- | ------------ |
| `maxresdefault` | 1280×720   | 16:9         |
| `sddefault`     | 640×480    | 4:3          |
| `hqdefault`     | 480×360    | 4:3          |
| `mqdefault`     | 320×180    | 16:9         |
| `default`       | 120×90     | 4:3          |

One catch: not every video has `maxresdefault`. Older videos or lower-quality uploads may only have SD and below. In that case, the max-res URL returns a 404 and you fall back to `sddefault`.

## Extracting the Video ID

The trickier part isn't the image URL — it's reliably pulling the video ID from whatever URL format you're given. YouTube has six:

```
youtube.com/watch?v=VIDEO_ID          // Standard
youtu.be/VIDEO_ID                     // Short link
youtube.com/embed/VIDEO_ID            // Embed
youtube.com/shorts/VIDEO_ID           // Shorts
youtube.com/live/VIDEO_ID             // Live streams
VIDEO_ID                              // Raw 11-char ID
```

You need a regex for each pattern. Miss one and you'll silently fail on a valid URL.

## Why Bother with a Tool Then?

If the URL pattern is simple, why build a tool around it?

A few reasons:

- **You still need to parse the video ID** from whatever URL you paste — handling all six formats correctly is annoying to do manually every time.
- **You don't always know which sizes are available** for a given video. The tool checks all of them and only shows what actually exists.
- **Three actions per image** — copy the URL, copy the image directly to clipboard, or download as a file. Doing any of these manually from the raw CDN URL requires extra steps.
- **"Copy All URLs"** grabs every resolution at once, formatted for easy use.

The underlying API is dead simple. The ergonomics around it are what make it worth building.
