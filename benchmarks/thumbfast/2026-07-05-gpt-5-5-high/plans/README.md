## Findings considered and rejected

So nobody re-audits these:

- **Over-refund on partial multi-thumbnail failure** (`convex/editor.ts`
  finishGeneration): rejected — the early status guard
  (`thumbnail.status !== "processing" && !== "pending"` → skip) makes
  per-thumbnail refunds idempotent; refunding `cost/N` per failed thumbnail
  is the correct proportional behavior, not a double refund.
- **orgStats lazy-seed race / negative credit balance race**
  (`convex/orgStats.ts`, `convex/credits.ts`): rejected — Convex executes
  mutations with serializable OCC; conflicting transactions retry and re-read,
  so check-then-act within a single mutation is safe.
- **`expireStaleGeneration` refund truncated past 500 thumbnails**: rejected —
  generations cap at 4 thumbnails (`count` ≤ 4); the bound is unreachable.
- **Admin count fallback caps at 500 without UI hint**
  (`convex/admin/queries.ts`): by-design documented transition behavior
  (legacy capped-scan fallback until orgStats seeds); revisit only if the
  transition period drags on.
- **Unreachable `cancelled` check in `finishGeneration`**
  (`convex/editor.ts:1360-1365`): true positive but dead-code-only — the
  preceding status guard already returns; fold the deletion into any future
  edit of that function, not worth a standalone plan.
- **Auth-guard "flash of content"** (`client-route-guard.tsx`): the repo's
  chosen `ssr:false` client-guard pattern; skeleton contains no sensitive
  data.
- **Missing `generateMutation` effect dependency** (`editor-form.tsx:412`):
  intentional, explicitly eslint-disabled; mutation refs are stable.
- **Star-toggle rapid-click race** (`generation-gallery.tsx`): already
  guarded by `isStarring`; residual window is cosmetic.
- **`useElapsedSeconds` clock-skew**: cosmetic, `Math.max` already floors it.
- **Optimistic image rename without rollback** (`editor-form.tsx:496`,
  finding F5): real but minor and not selected for planning this round —
  candidate for a future batch.
- **`getYoutubeVideoInfo` "orphaned"**: false — used by
  `convex/inspirationActions.ts`.
