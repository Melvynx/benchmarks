# Landing Page Copywriting: Thumbnail.io

## Target Audience Summary

**Primary Persona**: YouTuber Semi-Pro

- Creates 1-2 videos per week
- Spends 30-60 minutes per thumbnail
- Lacks design skills (Canva/Photoshop feel complex)
- Struggles to maintain consistent face/style across videos
- Wastes time browsing for thumbnail inspiration

**Pain Points**:

1. Time drain: Thumbnails eat into content creation time
2. Skills gap: Design tools have steep learning curves
3. Inconsistency: Same face = recreate everything each time
4. Inspiration paralysis: Finding reference thumbnails is tedious

**Goals**:

- Create 4-8 thumbnails/month quickly
- Test multiple variations
- Build recognizable channel brand
- Focus on content, not design

## Copywriting Framework

**Primary**: PAS (Problem-Agitate-Solution) + AIDA Hybrid
**Strategy**: Lead with the time/skill pain, agitate the frustration of inconsistency, then present the unique solution (reusable Persons + instant Inspirations). Build desire through features as benefits, close with strong CTAs.

## TONE & VOICE

**Overall**: Confident, direct, slightly irreverent. We're talking to busy creators who are sick of wasting time. No corporate speak - we're one of them.

**Words to use**:

- Seconds (not minutes)
- Generate (not create - implies AI)
- Instantly, immediately
- Click-worthy, viral-ready
- Consistent, recognizable
- Professional (without the hassle)

**Words to avoid**:

- Revolutionary, game-changing (overused)
- Cutting-edge AI (sounds generic)
- Easy (too vague - be specific)
- Cheap (say "affordable" or focus on value)
- Basic (sounds limiting)

**Sentence style**:

- Short sentences for impact
- Use "you" and "your" constantly
- Address pain directly, then pivot to solution
- Numbers are persuasive - use them
