A third image generation model is now available in the editor: **Nano Banana 2**, powered by Google's Gemini 3.1 Flash Image.

## Nano Banana 2

Nano Banana 2 is optimized for faster iterations and stronger text rendering. It uses the same Gemini API and prompt pipeline — the difference is the underlying model, built for speed and efficiency.

- **~4-6 seconds** per generation (vs ~8-12s for Pro)
- **Better text rendering** — cleaner letter shapes in generated images
- **More reference slots** — up to 10 objects + 4 characters per generation
- **Available on all plans** including free — no upgrade required

## Three Models to Choose From

You can now pick between three models in the editor:

- **Nano Banana Pro** — High-fidelity Gemini model
- **Nano Banana 2** — Recommended model for fast iterations and better text
- **GPT Image 2** — OpenAI's model (Pro plan only)

Switch models using the banana icon next to the credit balance. If you use your own Gemini API key, Nano Banana 2 works with the same key — no extra setup.

## When to Use It

Use Nano Banana 2 for quick iterations, bulk generation, and most thumbnails by default. Use Nano Banana Pro when you want the absolute best detail on a final photorealistic thumbnail. Both produce great results — Nano Banana 2 just gets there faster.
