# Changelog Rule

**CRITICAL: Update CHANGELOG.md after EVERY code change.**

1. Find or create today's date section: `## YYYY-MM-DD`
2. Add entry at TOP of section: `TYPE: Short description`
3. Types: `FIX:`, `FEATURE:`, `REFACTOR:`, `CHORE:`
4. Present tense ("Add", "Fix", not "Added", "Fixed")

NON-NEGOTIABLE. Every code change = changelog entry.
