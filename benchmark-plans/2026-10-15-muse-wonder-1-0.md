## Muse Wonder Full 1.0 (added 2026-10-15T04:54Z)

Requested 2026-10-15: `muse-wonder-full-1.0` at medium and xhigh on the same six tasks, in this same group, through the same `muse` harness and subscription. 12 more concurrent sessions, launched directly with `--benchmark-id` because Portly was unresponsive.

Wonder Full is subscription-only (Muse Code Power and Maximum plans) and Meta publishes no token price. Token counts are exact; dollar costs use Muse Wonder 1.0 API rates as an assumed equivalent and are flagged as estimates (`model-pricing.ts` label, `model_usage.<model>.rateSource`, `cost_breakdown.estimated_rate_models`).

`analyze-session-usage.py` now also records web-search queries (Meta bills $2.50 per 1,000, added to `total_cost_usd`), tool calls by name for the main agent and subagents, subagent session count, and a `cost_breakdown`. The 12 Wonder runs were re-analyzed: only video-generation changed (+$0.005 each, 2 web searches).

Result: 12/12 harness-verified, built, served, captured, and validated; all 12 added to the comparison (59 apps). Estimated cost: medium $9.37 (85.1 min summed), xhigh $11.26 (115.4 min), against Wonder medium $7.81 / xhigh $7.53. 3d-car-crash xhigh renders an empty scene with the simulation stuck at 0 s (159 identical page errors, `Cannot read properties of undefined (reading 'length')`); that is a model bug, the medium run renders cleanly.

The first verification pass failed because four Wonder Full sessions left Vite dev servers running in their isolated workspaces on 9300-9303, so the assigned ports were taken. Those processes were stopped and every Full app was re-verified and captured on its own port.

## Tooling changes made for this plan

- `run-benchmark.sh`: new `muse` harness (ports 9300-9399). stdout goes to `transcript.jsonl` but carries only lifecycle events, so the full session log (`~/.local/share/muse/sessions/<date>/<session-id>/`, including reminder subagents) is copied to `muse-session/` next to it and both analyzers read that log.
- `analyze-session-usage.py`: sums `model_completed` usage across the session and its subagents. Muse `input_tokens` already include cached input. Reminder subagents run on Muse Spark 1.3, so `total_cost_usd` prices each model at its own Meta rate and `model_usage` keeps the split.
- `analyze-transcript.py`: classifies Muse assistant messages and tool calls. Reasoning is encrypted in the log, so it contributes no characters.
- `validate-benchmark-run.sh`: checks the `run.model.configured` model and the copied session log for Muse runs.
- `model-pricing.ts`: Muse Wonder 1.0 rates, with a test. Comparison UI recognizes the `muse` harness ("Muse Code").
